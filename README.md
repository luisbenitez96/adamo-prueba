# AdamoServices: prueba técnica

Login con contraseña temporal por correo y dashboard de clientes.

Stack: React + Vite (front), Node + Express (back), MongoDB, JWT.

> Este README se completa en el último paso del proyecto, con las instrucciones para ejecutarlo.

## Estructura

```
apps/api     Backend (Express + TypeScript)
apps/web     Frontend (React + Vite + TypeScript)
design/      Recursos exportados de Figma
```
